## 4. Limits, SSML, alignment, and endpoint fit

- **Text length:** the app truncates at 1500 characters (`advertisements.service.ts`);
  the live 1500-character call succeeded. The provider maximum is not published in the
  consulted API docs and was not exhaustively probed.
- **SSML:** official API documents `input.enable_ssml=true`; the two candidate voices are
  listed as SSML-supported. Current integration does not expose it.
- **Alignment:** official API documents word timestamps for streaming output only;
  current non-streaming wrapper returns no timestamps. `audio-analysis.ts` remains
  segment-based and null-safe.
- **Model/endpoint fit:** official non-real-time guide and HTTP API list
  `qwen-audio-3.1-tts-flash` on the Singapore/Beijing SpeechSynthesizer endpoint, and the
  live international-endpoint calls succeeded with the configured model.
